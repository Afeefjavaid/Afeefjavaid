## 💫 About Me:
I'm a Software Engineering graduate from Pakistan, doing empirical research on how developers review and trust code written by AI coding agents. I'm always happy to collaborate on mining software repositories and human–AI trust research. I'm currently learning causal inference and LLM evaluation methods, and you can ask me about Python data analysis, Kotlin/Jetpack Compose, Next.js, or mining GitHub data.
